Пригадай

Колінеарні вектори і модуль

Колінеарні вектори — ненульові вектори, що лежать на одній прямій або на паралельних прямих.
Співнапрямлені (a ↑↑ b) — колінеарні й однаково напрямлені; протилежно напрямлені (a ↑↓ c) — колінеарні й напрямлені протилежно.
Модуль вектора a(x; y): |a| = x² + y².

Множення вектора на число

Теорія

Добуток вектора на число

Сума a + a + a — це вектор 3a. Він співнапрямлений з a, а його модуль утричі більший: |3a| = 3|a|.

Теорема (про добуток вектора на число).
Множимо вектор a на число λ (лямбда):
  1. Модуль вектора λa дорівнює |λ|·|a|.
    • Якщо λ > 0, вектор λa співнапрямлений з вектором a.
    • Якщо λ < 0, вектор λa протилежно напрямлений до вектора a.
    • Якщо λ = 0, то λa — нульовий вектор.
Наприклад:
−2a: протилежно напрямлений до вектора a, модуль удвічі більший.
12a: співнапрямлений з a, модуль удвічі менший.

Координати добутку вектора на число

Теорія

Відкриваємо правило з малюнка

Правило. Щоб помножити вектор на число, потрібно кожну його координату помножити на це число: вектор λa, де a(x; y), має координати (λx; λy).

Перевіримо на малюнку: a(2; 1). Вектори 3a і −2a побудовано від точки O.

Порахуй клітинки на малюнку:

3a(; )−2a(; )

За правилом: 3 · 2 = 6, 3 · 1 = 3; −2 · 2 = −4, −2 · 1 = −2. Збігається!

Властивості: для будь-яких векторів a і b та чисел α і β:
(α + β)a = αa + βa;
α(a + b) = αa + αb.
Протилежні вектори — вектори, що мають рівні модулі й протилежно напрямлені. Вектори a і −a — протилежні: a + (−a) = 0.

Умова колінеарності векторів

Теорія

Колінеарні вектори і число λ

Якщо b колінеарний вектору a, то b = λa, λ ≠ 0, і навпаки: якщо b = λa, λ ≠ 0, то a і b колінеарні.
Умова колінеарності. Нехай a(x1; y1) і b(x2; y2) — ненульові вектори.
1) Якщо x1 = x2 = 0, вектори колінеарні завжди:
◦ при y2y1 > 0: a ↑↑ b;
◦ при y2y1 < 0: a ↑↓ b.
2) Якщо y1 = y2 = 0, вектори колінеарні завжди:
◦ при x2x1 > 0: a ↑↑ b;
◦ при x2x1 < 0: a ↑↓ b.
3) Якщо усі координати не дорівнюють нулю і x2x1 = y2y1 = λ (відповідні координати пропорційні), то вектори колінеарні:
◦ при λ > 0: a ↑↑ b;
◦ при λ < 0: a ↑↓ b.
Наприклад:
a(2; 1), b(−4; −2). Заповни сам:
−42 = −21 = тому a b
a(2; 1), c(4; 3): 42 ≠ 31 — не колінеарні.
m(0; 3), n(0; −6): x1 = x2 = 0, −63 = −2 < 0, тому m ↑↓ n.
k(4; 0), p(2; 0): y1 = y2 = 0, 24 = 12 > 0, тому k ↑↑ p.

Цікавинка

🔍 Звідки слово «скаляр»?

Числа, на які множать вектори, називають скалярами — від латинського scala, «драбина», «шкала». Множення на число змінює масштаб вектора. Слова «вектор» і «скаляр» увів ірландський математик Вільям Гамільтон у 1840-х роках.

Коли ти збільшуєш мапу в телефоні, координати кожної її точки множаться на одне й те саме число. Так працює векторна графіка, тому лінії лишаються чіткими.
